Path 3 · Agentic Workflows

What Nate Herk's
videos actually teach.

Agents are AI that takes actions on your behalf — read your email, update a spreadsheet, post to social, qualify a lead, write a report. The YouTube hype calls it "agentic workflows". Here's the plain-English version, and which of n8n / Manus / Claude Agent SDK / Claude Code skills to actually pick.

The 30-second version. If you want a visual canvas like every YouTube video — use n8n (free, self-host or cloud). If you want code-based agents you fully control — Claude Agent SDK. If you want an agent that just does the work for you in a browser — Manus. If you live inside Claude Code already — use subagents, skills, hooks, MCP.
