Agents are AI that takes actions on your behalf — read your email, update a spreadsheet, post to social, qualify a lead, write a report. The YouTube hype calls it "agentic workflows". Here's the plain-English version, and which of n8n / Manus / Claude Agent SDK / Claude Code skills to actually pick.

Lesson 1

What an agent actually is

An agent is just an AI in a loop with two extra things: tools (the ability to call APIs / read files / send messages) and memory (the ability to keep going across multiple steps).

The loop

  1. Receive a goal ("qualify this lead")
  2. Decide what to do next (call CRM? search web? draft email?)
  3. Use a tool to do it
  4. Look at the result
  5. Decide if done, or go back to step 2

That's it. Everything else — n8n, MCP, skills, ReAct, planning — is implementation detail around this loop.

Lesson 2

The four shapes of agent

🔗
Visual canvas (n8n / Make / Zapier)

Drag nodes, wire them. Trigger → AI step → tool call → output. What 90% of YouTube videos show.

Pick if: you want speed without code, integration with hundreds of apps out of the box, and to share/sell flows.

🧠
Code SDK (Claude Agent SDK / OpenAI Agents)

Write the agent in Python or TypeScript. Define tools as functions. Deploy anywhere.

Pick if: you can code, want full control, need custom logic that visual tools struggle with.

🤖
Browser agent (Manus, OpenAI Operator)

Hand it a task in plain English. It opens a browser, clicks, types, fills forms — like a remote worker.

Pick if: the work is clicky / repetitive on websites that don't have APIs.

⌬
Inside Claude Code (subagents / skills / hooks / MCP)

Your coding agent gets richer abilities. Subagents handle parallel research. Skills add reusable knowledge. Hooks fire on events. MCP gives it tools.

Pick if: you live in Claude Code and want to extend it, not replace it.

Lesson 3

n8n — the YouTube favourite

Why every creator uses it

  • Free if you self-host. £18/mo cloud if you don't want to.
  • 400+ integrations out of the box (Gmail, Slack, Sheets, Airtable, Notion, X…)
  • The visual nodes look great on camera
  • You can sell flows as templates (creators do)

How an n8n agent flow looks

[ Schedule trigger: every hour ]
        ↓
[ Read Gmail: unread inbox ]
        ↓
[ AI Agent node: classify → "lead" / "spam" / "support" ]
        ↓
[ Switch ]
   ├── Lead → [ Add to CRM ] → [ Slack ping ]
   ├── Spam → [ Trash ]
   └── Support → [ Reply with template ]

Two-hour starter path

  1. Sign up at n8n.io cloud (or self-host with Docker).
  2. Create a workflow → drag a "Manual trigger" → add an "AI Agent" node → connect OpenAI / Anthropic.
  3. Try the prompt: "You are a research assistant. When given a company name, find their website, summarise what they do in 2 sentences."
  4. Add an "HTTP Request" tool to the agent so it can fetch URLs.
  5. Run it. Iterate.
Lesson 4

Claude Agent SDK — code-based

If you can code, the SDK gives you the same power as n8n with no UI overhead. Define tools as Python functions, plug them into a Claude agent, deploy as a script / Lambda / cron.

from anthropic import Anthropic
client = Anthropic()

def get_weather(city: str) -> str:
    return f"Sunny, 22°C in {city}"  # real impl would call an API

response = client.messages.create(
    model="claude-sonnet-4-6",
    max_tokens=1024,
    tools=[{
        "name": "get_weather",
        "description": "Get current weather for a city",
        "input_schema": {
            "type": "object",
            "properties": {"city": {"type": "string"}},
            "required": ["city"]
        }
    }],
    messages=[{"role": "user", "content": "Should I bring an umbrella in London?"}]
)

The model decides when to call get_weather, you execute it, feed the result back, repeat. That's an agent.

Lesson 5

Three starter workflows

1. Lead-gen agent

What it does: takes a list of company names, finds their site + LinkedIn + key person, scores fit against your ICP, drops qualified ones into a CRM with a personalised first-line.

Build it in: n8n. Nodes: Google Sheet → Loop → AI Agent (with web search tool) → Conditional → CRM (HubSpot / Airtable) → Slack alert.

2. Content repurposing agent

What it does: watches a folder for new transcripts → extracts 5 quote-worthy lines → generates 3 LinkedIn posts, 3 tweets, 1 blog outline → drops into a "ready to post" doc.

Build it in: n8n + Notion. Trigger on new file → Whisper for audio → AI Agent with brand-voice system prompt → Notion DB.

3. Inbox triage agent

What it does: reads incoming Gmail → classifies (urgent / can-wait / promo / newsletter / FYI) → drafts replies for the templated ones → leaves the urgent ones at top of inbox with a summary line.

Build it in: n8n. Gmail trigger → AI classifier → Switch → templated Reply / Label / Archive.
